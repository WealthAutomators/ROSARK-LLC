# ROSARK LLC

Contemporary retail storefront for ROSARK LLC — a considered catalog of home, travel, apparel, and everyday objects.

Built on a shared Next.js ecommerce engine. Cart, wishlist, recently viewed, search, filters, demo checkout, and demo login remain client-side.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui + Radix UI
- Framer Motion
- Embla Carousel

## Scripts

```bash
npm run dev
npm run build
npm start
```
